One library for every SKILL.md, deployed by symlink to 54 AI coding agents — Claude Code, Codex, Cursor and the rest. Native macOS, free to use.

What it does

Install skills from a folder, a Git repo or the skills.sh marketLocalGitskills.shImportedand keep them in one library. Tick the agentsa skill should reach; each deployment is one symlink, so the files exist once. Save a set as a presetWeb stack8 skills · 4 agentsApplyand apply it on a new Mac. When a source moves on, the update badgeUpdate availablea41f0c2 → dbd4588says so, and one click follows.

No background process, no account. The library lives in ~/.skills-manager, the database is one SQLite file, and the command-line tool does everything the window does.

An agent's skills folder tends to collect things installed from elsewhere. Skills Manager lists them all: the managed ones, copies that match the library, folders the library has never seen — import, adopt, or delete.

  3. Automate

    skills-manager-cli does everything the window does — for scripts, dotfiles and the setup of a new machine.

    $ skills-manager-cli install \
    https://github.com/anthropics/skills/tree/main/skills/pdf
Installed pdf → ~/.skills-manager/skills/pdf
$ skills-manager-cli deploy pdf cursor claude_code codex
Deployed pdf → cursor (symlink) ~/.cursor/skills/pdf
Deployed pdf → claude_code (symlink) ~/.claude/skills/pdf
Deployed pdf → codex (symlink) ~/.codex/skills/pdf
$ skills-manager-cli update # every git and skills.sh skill
$ skills-manager-cli doctor # fix broken links, re-sync records

Homebrew

With Homebrew, it is one line:

brew install --cask ddhjy/tap/skills-manager

Later: brew upgrade --cask skills-manager

This device is not a Mac. Skills Manager is macOS-only — send the link to your Mac.

This Mac runs macOS 15; Skills Manager needs macOS 26 or later.

Nothing is uploaded, nothing is counted. Skills Manager has no account and collects no data. It goes online only when you ask it to: cloning a Git repository, talking to skills.sh, pushing or pulling a backup, and once a day asking GitHub whether there is a new version.

Questions

Symlinks or copies?

Symlinks by default: the agent's skills folder holds one link to the single copy in the library, so a change in the library reaches every agent at once. For the odd agent that does not follow symlinks, a skill can be switched to copy mode, and Skills Manager refreshes the copy when the source updates.

Where is the library?

~/.skills-manager/skills, next to a SQLite database. To put it elsewhere, set the SKILLS_MANAGER_HOME environment variable; the command line also takes --library.

My agent was not detected.

Detection looks for the agent's config folder in your home directory (such as ~/.cursor). Enable it by hand under Settings → Agents, or point Skills Manager straight at its skills folder.

What about project-level skills?

Add a project workspace: skills are deployed into .cursor/skills, .claude/skills and the like inside the project folder, managed apart from the global ones.

How do I sync a second Mac?

Backup pushes the library to a Git repository of your choice; pull it on the new Mac, apply a preset, and the deployments are back.

macOS says it cannot verify the developer.

Official releases are signed with Developer ID and notarised by Apple. If this message still appears, download and reinstall the latest release from this website. If it persists, report the app and macOS versions on GitHub.

How do I update? How do I uninstall?

The app checks for a new version once a day, and the menu has “Check for Updates…”; Homebrew users run brew upgrade --cask skills-manager. To uninstall, move the app to the Trash (Homebrew: brew uninstall --cask skills-manager); the library is in ~/.skills-manager if you want that gone too.

Where are release notes and issue reports?

Downloads and release notes are on GitHub Releases. Report problems in Issues. The source repository is currently private.

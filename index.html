Skills Manager
功能怎么用Agent安装
下载

技能只装一次，都能用。

把所有 SKILL.md 放进一个库，用符号链接部署到 Claude Code、Codex、Cursor 等 54 个 AI 编程 Agent。原生 macOS 应用，免费使用。

功能一览

从本地文件夹、Git 仓库或 skills.sh 市场本地Gitskills.sh导入安装技能，全部收进一个库。勾选要给哪些 Agent用，每次部署只是一条符号链接，文件始终只有一份。把常用组合存成预设Web 前端8 个技能 · 4 个 Agent应用带走，换台 Mac 一键应用。来源有了新版本，更新标记有可用更新a41f0c2 → dbd4588会告诉你，一键跟进。

没有后台进程，没有账号。库在 ~/.skills-manager，数据库是一个 SQLite 文件，命令行工具能做界面里的每一件事。

免费下载

每个 Agent 一页，看它手里到底有什么。

Agent 的 skills 目录里常常混着别处装的东西。Skills Manager 把它们列出来：已托管的、和库里一致但还是副本的、库里没有的——导入、接管，或者删掉。

  3. 自动化

    skills-manager-cli 能做界面里的每一件事，写进脚本、dotfiles 或新机器的初始化里。

    $ skills-manager-cli install \
    https://github.com/anthropics/skills/tree/main/skills/pdf
Installed pdf → ~/.skills-manager/skills/pdf
$ skills-manager-cli deploy pdf cursor claude_code codex
Deployed pdf → cursor (symlink) ~/.cursor/skills/pdf
Deployed pdf → claude_code (symlink) ~/.claude/skills/pdf
Deployed pdf → codex (symlink) ~/.codex/skills/pdf
$ skills-manager-cli update # every git and skills.sh skill
$ skills-manager-cli doctor # fix broken links, re-sync records

Homebrew

有 Homebrew 的话，一句话：

brew install --cask ddhjy/tap/skills-manager

以后更新：brew upgrade --cask skills-manager

这台设备不是 Mac。Skills Manager 只有 macOS 版——把链接发到你的 Mac 上吧。

这台 Mac 运行的是 macOS 15，Skills Manager 需要 macOS 26 或更高。

不上传，不统计。Skills Manager 没有账号，也不收集任何数据。它只在你让它做事时联网：克隆 Git 仓库、访问 skills.sh、推送或拉取备份，以及每天一次向 GitHub 询问有没有新版本。

问答

部署是符号链接还是复制？

默认是符号链接：Agent 的 skills 目录里只有一条链接，指向技能库里唯一的一份文件，库里一改，所有 Agent 同时生效。个别不跟随符号链接的 Agent 可以改成复制模式，来源更新时 Skills Manager 会刷新副本。

技能库在哪里？

~/.skills-manager/skills，旁边是一个 SQLite 数据库。想放到别处，设置环境变量 SKILLS_MANAGER_HOME，命令行也接受 --library。

我的 Agent 没有被检测到？

检测依据是主目录里有没有它的配置文件夹（比如 ~/.cursor）。到「设置 → Agent」里手动启用它，或者直接指定它的 skills 目录。

项目级的技能怎么办？

添加一个项目工作区，技能会部署到项目目录里的 .cursor/skills、.claude/skills 等位置，与全局的分开管理。

换了一台 Mac 怎么同步？

「备份」会把技能库推送到你指定的 Git 仓库；在新 Mac 上拉取，再应用预设，部署就回来了。

打开时提示无法验证开发者？

正式发布均使用 Developer ID 签名并经过 Apple 公证。如果仍出现此提示，请从官网下载最新版本重新安装；问题持续时，请在 GitHub 反馈应用版本和 macOS 版本。

怎么更新？怎么卸载？

应用每天检查一次新版本，菜单里也有「检查更新…」；Homebrew 用户执行 brew upgrade --cask skills-manager。卸载就是把应用移到废纸篓（Homebrew：brew uninstall --cask skills-manager）；技能库在 ~/.skills-manager，不要了一并删掉。

在哪里查看发布记录和反馈问题？

版本发布和更新日志在 GitHub Releases，问题反馈请使用 Issues。当前源码仓库未公开。

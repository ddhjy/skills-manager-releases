# Skills Manager

A native macOS app for installing AI coding agent skills once and deploying them to multiple agents.

Requires macOS 26 or later. Official releases support Apple silicon and Intel Macs, are signed with Developer ID, and are notarized by Apple.

- [Website](https://skillsmanager.suixinapp.com/) · [English](https://skillsmanager.suixinapp.com/en/)
- [Downloads and release notes](https://github.com/ddhjy/skills-manager-releases/releases)
- [Report a problem](https://github.com/ddhjy/skills-manager-releases/issues)

## Installation

Download the DMG from Releases and drag **Skills Manager.app** into Applications.

Homebrew:

```sh
brew install --cask ddhjy/tap/skills-manager
```

To update, use **Skills Manager → Check for Updates…** or `brew upgrade --cask skills-manager`.

Release assets include the DMG, ZIP, `SHA256SUMS.txt`, and the application update manifest `latest.json`.

This repository hosts public releases, the website, and issue reports. The application source repository is private.
